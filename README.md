# 🎮 Archipelago Stream Tool

Un outil web universel et "Plug & Play" pour streamer vos parties Multiworld (Archipelago) sur OBS.
Il génère un overlay dynamique combinant les flux vidéos des joueurs, un journal des événements en direct, des alertes sonores (DeathLink) et un compteur d'objets.

## 🚀 Comment l'utiliser ?

1. Rendez-vous sur la page générée par GitHub Pages (le Control Panel).
2. Entrez l'adresse de votre serveur Archipelago et votre pseudo.
3. Personnalisez vos couleurs.
4. Ajoutez les pseudos de vos amis et leurs liens vidéos (Twitch, YouTube ou VDO.Ninja).
5. Cliquez sur **Générer le lien magique OBS**.
6. Dans OBS Studio, ajoutez une **Source Navigateur**.
7. Collez le lien magique, réglez la taille sur `1920x1080`, et cochez *Contrôler l'audio via OBS*.

## 🛠 Fonctionnalités

*   **Universel :** Supporte Twitch, YouTube et VDO.Ninja.
*   **Intelligent :** Se reconnecte automatiquement au serveur en cas de coupure.
*   **Tracker intégré :** Compte visuellement les objets trouvés par chaque joueur.
*   **Personnalisable :** Changez les couleurs de l'interface depuis le Control Panel.
